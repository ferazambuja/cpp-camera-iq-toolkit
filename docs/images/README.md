# Illustrative test-capture crops

These reduced crops come from source captures analyzed by this project. They
show the physical target structures used for patch, slanted-edge, and Stepchart
measurements:

- `colorchecker-sg-patch-grid.jpg` — central patch grid used to illustrate
  ColorChecker-SG sampling.
- `sfr-field-target.jpg` — slanted-edge regions distributed across an SFR
  target.
- `oecf-stepchart-zones.jpg` — central tonal structures from the ring-layout
  Stepchart capture.
- `flat-field-sphere.jpg` — full reduced view of the integrating-sphere field
  used for the CFA response characterization.

All images are compressed and stripped of capture metadata. The target crops
intentionally omit the full target artwork and original file identity. These are
visual illustrations, not downloadable calibration references or analysis
inputs. The numerical results use the source RAW captures configured outside
Git.
